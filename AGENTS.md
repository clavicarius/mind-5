# AI agent instructions

## Branching model

- Submit changes through pull requests targeting `main`; do not push directly to `main`.
- Use `<prefix>/<name>` for pull request source branches, where `<name>` contains only lowercase letters, numbers, dots, underscores, and hyphens.
- Allowed prefixes are `feature`, `enhancement`, `bugfix`, `hotfix`, `release`, `chore`, and `copilot`.
- Use `copilot/` for branches created by AI agents.
- Follow `docs/BRANCHING_MODEL.md` for the complete branching and release process.

## Changes

- Keep changes focused and consistent with the existing project documentation.
- Run the applicable checks and tests before submitting a pull request.
